# makora

A self-evolving agent harness for long-running tasks, built on [pi-durable](../../packages/durable). This is phase 1:
the app skeleton. See [the docs](../../docs/README.md): [vision](../../docs/vision.md), [roadmap](../../docs/roadmap.md) and
[decisions](../../docs/decisions.md).

## Run

Requires Node 22.19+ and the monorepo's installed dependencies and model data. From the repository root:

```sh
npm install --ignore-scripts
npm run hydrate:model-data
cd apps/makora
npm start                      # TUI, new session in the current directory
```

`bin/makora.mjs` runs the same entry from any directory (`ln -s "$PWD/bin/makora.mjs" ~/.local/bin/makora`).

| Command | What it does |
| --- | --- |
| `makora` | New session in the current directory |
| `makora --continue` | Latest session of the current directory |
| `makora --resume [id]` | A session by id, or a picker |
| `makora ls` | List sessions |
| `makora -p "<prompt>"` | Print mode: streams the answer to stdout, tool calls to stderr, exit 1 when unanswered |
| `--fake` | Uses a scripted fake model; no provider is called, but tools act on real files |
| `--model provider/id` | Model for this run |

Data lives in `~/.makora` (`MAKORA_HOME` overrides it): `sessions/<id>/session.sqlite` per session, `auth.json`,
`settings.json`, `keybindings.json`, and optional `AGENTS.md` and `skills/`.

## Login

`/login` connects a provider. Claude Pro/Max logins use Anthropic's OAuth flow; Anthropic bills this usage as extra
usage, not against plan limits. Each login with a new identity adds an account; `/accounts` switches or removes
them. The status line shows the active account, plan usage when available, and a warning before the 30-day grant ends.

## Skills

pstack and no-mistakes are bundled in `skills/`, generated by `scripts/sync-skills.mjs` from the pins in
`skills.lock.json`. Never edit `skills/` by hand: change `skills-src/` (the makora adapter and overlays) and rerun
`node scripts/sync-skills.mjs`. `--check` verifies the tree, `--latest` repins upstream. The `makora-skills` workflow
checks every PR and opens a daily sync PR; it needs the repository secret `MAKORA_BOT_TOKEN`. The `no-mistakes`
binary is installed separately.
